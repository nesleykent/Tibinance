✓ Screenshots and character names are never kept — only anonymous market data. What exactly?
Written to the database

World, Type, BattlEye, Sell, Sell Volume, Gold Demand, Buy, Buy Volume, Gold Supply, Capture Date, Screenshot Hash.

Eleven fields. Nothing else can be written — the code builds each record from that fixed list.

Never written anywhere

The screenshot itself, the filename, and the character name in it.

The image is decoded, read, then dropped; only the SHA-256 of its bytes is kept, to spot a screenshot you already processed. The character name is used for the TibiaData world lookup and discarded. Both appear on screen while you review a card — that is the browser showing you the file you just dropped, not the database.
